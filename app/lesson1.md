# Типы данных в Go

## Базовые типы

| Тип | Описание | Пример |
|---|---|---|
| bool | логический тип | true, false |
| string | строка | "hello" |
| int | целое число | 10 |
| float64 | дробное число | 10.5 |

## Целые числа со знаком

| Тип | От | До |
|---|---:|---:|
| int8 | -128 | 127 |
| int16 | -32 768 | 32 767 |
| int32 | -2 147 483 648 | 2 147 483 647 |
| int64 | -9 223 372 036 854 775 808 | 9 223 372 036 854 775 807 |
| int | зависит от системы | зависит от системы |

## Целые числа без знака

| Тип | От | До |
|---|---:|---:|
| uint8 | 0 | 255 |
| uint16 | 0 | 65 535 |
| uint32 | 0 | 4 294 967 295 |
| uint64 | 0 | 18 446 744 073 709 551 615 |
| uint | 0 | зависит от системы |

## Псевдонимы

| Тип | То же самое | От | До |
|---|---|---:|---:|
| byte | uint8 | 0 | 255 |
| rune | int32 | -2 147 483 648 | 2 147 483 647 |

## Дробные числа

| Тип | Описание |
|---|---|
| float32 | дробное число обычной точности |
| float64 | дробное число повышенной точности |

## Комплексные числа

| Тип | Описание |
|---|---|
| complex64 | комплексное число на основе float32 |
| complex128 | комплексное число на основе float64 |

## Составные типы

| Тип | Описание | Пример |
|---|---|---|
| array | массив фиксированной длины | [3]int |
| slice | динамический массив | []int |
| map | коллекция ключ значение | map[string]int |
| struct | структура с полями | type User struct |
| pointer | указатель | *int |
| function | функция как значение | func(int, int) int |
| interface | набор методов | interface{} |
| channel | канал для горутин | chan int |

## Нулевые значения

| Тип | Нулевое значение |
|---|---|
| int | 0 |
| float64 | 0 |
| string | "" |
| bool | false |
| pointer | nil |
| slice | nil |
| map | nil |
| function | nil |
| interface | nil |
| channel | nil |
